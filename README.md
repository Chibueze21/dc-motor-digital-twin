# DC Motor Digital Twin & Control Lab

A computational study of DC motor modeling, simulation, control,
system identification, and digital-twin development.

## Objectives

- Develop a mathematical model of a DC motor.
- Implement numerical simulation.
- Design and evaluate PID control.
- Investigate state-space control.
- Perform parameter/system identification.
- Compare simulated and identified models.
- Develop the foundation for a digital twin.
- Explore machine-learning augmentation of the model.

## Technology

- Python
- NumPy
- SciPy
- Matplotlib
- Git
- C/C++
- CMake
